About this site

An independent, non-partisan civic-info resource for the 28 November 2026 Victorian state election. Built to help readers understand how the election works and see what's on their ballot.

Non-partisan commitment

This site does not endorse any party, candidate, or outcome. Every party summary and policy comparison is drawn from the parties' own public materials and framed neutrally. Candidate lists are reproduced from Wikipedia and the ABC's candidate guide. If a particular paragraph looks like editorialising, flag it — treat the source link as canonical, not this site.

Where the data comes from

  • Electoral boundaries — Vicmap Admin via the Victorian Government's open data portal (© State of Victoria, CC BY 4.0). Simplified for web rendering.
  • Current MPs and MLCs (60th Parliament) — Wikipedia's lists for the 2022–2026 term, cross-referenced with Parliament of Victoria.
  • 2026 candidates — Wikipedia's running tally. The authoritative list is published by the Victorian Electoral Commission after nominations close on 9 November 2026.
  • 2022 and 2018 district margins — Wikipedia's "Results of the … Victorian state election (Legislative Assembly)" articles, which in turn cite the VEC.
  • Opinion polling — Wikipedia's running poll tracker for the 2026 Victorian state election.
  • Candidate bios — Wikipedia for sitting members, the ABC's 2026 candidates guide and individual party sites for non-sitting candidates.
  • Party platforms — paraphrased from each party's own website, cited on the Compare parties page.
  • Election rules, dates, voting mechanics — the Victorian Electoral Commission.

About the 2026 projection

The "projected 2026" number on each district panel is a uniform-swing projection: take the average two-party-preferred (2PP) from the most recent polls, calculate the swing since 2022's state-wide 2PP of 55% Labor, and apply that swing to every Labor-vs-Coalition seat. Full method and caveats on the Polling page. It is not a prediction — real swings vary by seat, and local candidate effects, independents and preference-flow changes can all move things materially.

Found an error?

If a number looks wrong, a party platform misrepresents a position, a candidate is missing or miscategorised, or a bio is about the wrong person — please let us know by opening a GitHub issue. Include the page, the specific error, and ideally a link to the correct source. If multiple things are wrong, one issue per thing is easier to action.
